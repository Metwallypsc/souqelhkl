# سوق الحقل - القرار التقني وخطة التنفيذ

## القرار التقني

سيتم بناء المشروع كـ modular monolith في البداية، لأن النسخة الأولى تحتاج سرعة ووضوح في التشغيل مع قابلية توسع لاحقة بدون تعقيد مبكر.

الستاك المقترح:

- Next.js App Router + TypeScript
- PostgreSQL كقاعدة بيانات أساسية
- Prisma ORM لإدارة schema والمigrations
- Tailwind CSS لدعم واجهة عربية RTL بسرعة وانضباط
- Zod للتحقق من بيانات النماذج والطلبات
- تخزين الصور لاحقا عبر S3-compatible storage أو Cloudinary/Supabase Storage حسب قرار الاستضافة

## لماذا هذا مناسب لسوق الحقل

- يدعم متجر وداشبوردات في نفس المشروع.
- مناسب للـ SEO وصفحات المنتجات.
- يسمح ببناء API داخلي تدريجيا بدون فصل مبكر.
- PostgreSQL مناسب لعلاقات المنتجات، البائعين، الطلبات، العمولات، وحالات الطلب.
- Prisma يجعل نموذج البيانات واضحا وقابلا للمراجعة.

## التقسيم البرمجي المقترح

- catalog: التصنيفات، المنتجات، الصور، الفلاتر.
- listings: عروض البائعين، السعر، المخزون، وحدات البيع، الاختيارات.
- cart: السلة متعددة البائعين.
- checkout: العنوان، طريقة الدفع، حساب الشحن.
- orders: دورة حياة الطلب، قبول/رفض البائع، الإلغاء قبل الشحن.
- payments: الدفع عند الاستلام، InstaPay، مراجعة صورة التحويل.
- shipping: مركز التجميع، قواعد الوزن، الإضافات اليدوية.
- commissions: حساب 1% بعد اكتمال الطلب.
- admin: إدارة البائعين، الموافقات، الطلبات، الإعدادات.
- vendor: لوحة البائع للمنتجات والطلبات.

## قواعد مهمة في التنفيذ

- لا يتم الاعتماد على السعر القادم من المتصفح عند إنشاء الطلب؛ يتم إعادة حساب السعر من قاعدة البيانات.
- المنتج غير المتوفر لا يدخل السلة.
- كل طلب يأخذ snapshot من اسم المنتج، اسم البائع، السعر، الوحدة، والاختيارات وقت الشراء.
- الشحن في النسخة الأولى configurable:
  - 100 جنيه حتى 10 كيلو.
  - كل زيادة فوق 10 كيلو، حتى لو جرام، تضيف 25 جنيه لكل بلوك 10 كيلو أو جزء منه.
  - أي منتج كبير يمكن إضافة تكلفة يدوية له من لوحة الإدارة.
- عمولة المنصة لا تنشأ كقيمة نهائية إلا بعد اكتمال الطلب.
- كل تعديل إداري مهم يسجل في audit log.

## خطة التنفيذ المرحلية

1. إنشاء السكافولد الأساسي للواجهة وقاعدة البيانات.
2. بناء seed data للتصنيفات والإعدادات الأولية.
3. بناء صفحات المتجر: الرئيسية، التصنيفات، البحث، صفحة المنتج.
4. بناء حساب العميل والسلة والcheckout.
5. بناء لوحة الإدارة: البائعين، المنتجات، الموافقات، الطلبات.
6. بناء لوحة البائع: إضافة/تعديل المنتجات، قبول/رفض الطلبات.
7. إضافة InstaPay upload review.
8. إضافة حساب العمولة وتقارير الطلبات الشهرية.

## ما تم إنشاؤه حاليا

- مشروع Next.js/TypeScript داخل مجلد `work`.
- واجهة رئيسية عربية أولية.
- إعداد Tailwind RTL.
- Prisma schema مبدئي يغطي الكيانات الأساسية.
- ملف بيئة مثال `.env.example`.
